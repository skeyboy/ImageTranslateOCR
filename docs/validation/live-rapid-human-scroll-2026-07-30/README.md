# 快速连续滑动清理与原子回贴验证

日期：2026-07-30  
设备：Xiaomi 23113RKC6C（无线 ADB）  
回退节点：`6f131e0 feat: checkpoint experimental translation engines`

## 目标与视频对照

参考视频在拖动开始后的一个渲染帧内撤掉旧译文，拖动和惯性阶段只显示原文，最后一个视口停稳后再整层一次性回贴。用户问题中的叠字不是单纯 OCR 准确率问题，而是旧贴图生命周期和异步结果时序问题。

本轮按以下状态约束实现：

1. 首次检测到运动即清空并回收旧贴图 Bitmap。
2. 递增 generation，取消旧处理任务，并禁止恢复上一个结果。
3. 连续滑动期间只更新运动状态，不提交 OCR 结果。
4. 最后视口稳定后只处理最新 generation。
5. 结果进入主线程时再次校验 generation；失效结果只回收，不展示。
6. 新结果整组原子替换，不逐行追加。
7. 旧任务的“处理中”状态也在主线程执行前校验 generation。
8. 默认模式保留半透明译文像素中的底层运动信号，避免大面积贴图屏蔽正文滑动。
9. 增强模式的无障碍滚动事件与帧检测统一在采集线程串行处理。
10. 译文提交后 420ms 内只屏蔽贴图区域的合成变化，未覆盖的页面区域仍持续检测快速滑动；该窗口内检测到滑动时使用整屏识别，不采用可能偏置的差分位移计划。
11. 被新滑动抢占且尚未启动的识别任务也会释放 `Image`，避免耗尽采集缓冲区后长期无结果。
12. OCR 成功或失败后的 generation 校验与采集状态提交统一在采集线程串行执行，旧结果不能在新滑动清理后把 `presentationInProgress` 写回。

## 真人手势模型

`SCROLL_GESTURE_PROFILE=HUMAN_BURST` 每轮执行 3 次手势，共覆盖四种操作：

- 长拖后两次短甩
- 连续三次快速短甩
- 中途犹豫停顿后继续滑动
- 不等距离、不同速度的混合甩动

首轮手势开始 220ms 时并行抓取 `during-first-motion.png`，截图 I/O 不阻塞后续手势。截图中只有底层英文原文和“等待停稳”状态，不存在旧译文贴图。

## 实机结果

| 指标 | 修复前回退 APK | 修复后默认模式 | 修复后增强模式 |
| --- | ---: | ---: | ---: |
| 完成轮数 | 3/4（无线 ADB 中断） | 4/4 | 4/4 核心手势 |
| 每轮手势数 | 3 | 3 | 3 |
| 单次清理 + 单次提交 | 3/3 | 4/4 | 4/4 |
| 可证明物理清理 | 不支持该 telemetry | 4/4 | 4/4 |
| 运动到清理 P90 | 样本不完整 | 47ms | 43ms |
| 最后运动到提交 P90 | 样本不完整 | 1481ms | 1568ms |
| 静止 15 秒额外识别 | 未完成 | 0 | 本轮未执行（上一完整批次为 0） |
| 旧 generation 回贴 | 无守卫指标 | 0 | 0 |
| 点击透传 | 3/3 | 4/4 | 4/4 |

最新默认模式的全部自动化门禁通过，固定彩色非文字标记与浏览器栏 SSIM 均为 `1.0`，没有为了通过验收而降低 `0.97`/`0.99` 阈值。最新增强模式四轮手势均通过滚动、点击透传、单次物理清理、单次原子提交和 generation 新鲜度检查；无线 ADB 在四轮结束后的静止/切换/退出阶段断开，因此这些后置门禁沿用上一完整增强批次的通过结果，不将其记为本轮重新通过。一个较早的增强探索批次曾得到标记 SSIM `0.956020`，因此非文字贴图边界仍保留为后续回归关注项。

`default-final-v8` 与 `enhanced-final-v8` 是最终并发复核前的候选版实机数据。复核随后发现“译文出现后 420ms 内立即短甩”与“结果校验后被滑动插入”两个边界竞态；最终实现已用贴图区域临时屏蔽和采集线程串行提交修复，并增加 JVM 回归用例。设备无线调试端口随后离线，因此最终边界修复已完成构建与自动化测试，但没有把候选版实机数值冒充为最终修复的重新实测结果。

## 结论

保留本轮生命周期修复、主线程 generation 二次校验、物理清理 telemetry、420ms 贴图区域临时屏蔽、采集线程串行提交和真人手势验证脚本。候选版默认与增强模式均满足快速滑动阶段“立即清空、最后视口只贴一次、页面仍可点击”的核心目标；最终边界修复再消除了紧接译文出现的短甩盲区与旧任务状态回写竞态。默认候选版完成全门禁，增强候选版本轮只对核心滑动路径作结论，最终版仍需在设备重新连接后补跑同一批手势。

修复前同视口对照因无线设备在第 4 轮断开，只作为不完整样本：它未在前三轮稳定复现叠图，但旧版本只能把 View 设为不可见，仍持有 Bitmap，并且缺少主线程提交前的最终 generation 校验，无法消除已知竞态。

后续独立处理非文字保护区域：在贴图边界扩展前加入控件/图形置信度屏蔽，继续沿用 `0.97` SSIM 门禁验证，避免把不相关的 P2 视觉问题混入本轮 P0/P1 滑动修复。
