# 连续滚动、原子呈现与触摸透传验证

> 执行日期：2026-07-29
>
> 设备：Xiaomi `23113RKC6C`，Android 16，1440x3200，竖屏亮色
>
> 配置：英译中、Reading/Accuracy、普通悬浮窗 `alpha=0.72`、局部背景、背景效果关闭
>
> 基线：[实时屏幕翻译产品场景与验收基线](../../live-screen-translation-product-acceptance-baseline.md)

## 1. 结论

本轮设计并执行了一个真实 MediaProjection 连续翻译场景。30 次滚动、30 次底层点击、15 秒静止检查和一次原文/译文切换均完成，A3、A4、A8、A9 通过；A7 的“整组原子呈现”和“受保护非文本区域”自动子项通过。

完整 A7 只能判定为 **PARTIAL / 部分通过**。关键帧仍有明显灰色矩形、代码区中英混排及段落切碎；30 轮累计 17 个失败区域。本轮没有黄金 OCR/译文标注，`semantic_quality_evaluated=false`，因此不替代 A5/A6，也不能据此宣布产品视觉或语义质量通过。

生产决策不变：普通模式继续使用 `alpha=0.72` 局部背景且背景效果默认关闭；不启用全页主题色。下一视觉优化应优先验证 OCR 字形遮罩、羽化边缘和代码/非文字保护，而不是扩大整页纯色或高斯覆盖。

## 2. 目标：最终要证明或交付什么

证明用户在外文长文中持续滚动时，旧译文会快速失效，稳定视口只提交一组新译文；翻译层不阻断网页点击，原文/译文切换不改变阅读位置，图表、固定标记及浏览器栏不被译文层污染。

交付物：

- 可重复执行的混合长文测试页和真机自动化脚本。
- 30 轮逐次 JSONL、汇总 JSON、首/中/末关键帧、切换对照图和两段全程录屏。
- 对 A3、A4、A7、A8、A9 的机器判定，以及与机器门分离的人工视觉结论。

## 3. 真实场景：用户实际如何使用

页面模拟英文技术文档阅读：固定站点栏下包含 36 个长段落、代码块、Canvas 柱状图、分隔线和固定彩色标记。用户开启持续翻译后连续向下阅读，期间点击固定测试控件，并在末尾切回原文核对内容。

交互遵循即时反馈、空间连续和可逆性原则：手势开始立即隐藏旧译文，停稳后整组呈现新结果；原文切换保持同一滚动锚点；系统栏、浏览器栏和非文本结构始终保留。

## 4. 验收：逐项列出可操作标准

| 项目 | 可操作标准 | 实测 | 判定 |
| --- | --- | --- | --- |
| A3 滚动稳定性 | 30 次滚动均产生位移；每次最多一次 OCR 完成；静止 15 秒新增识别为 0 | 30/30；每轮完成数均为 1；空闲活动 0 | PASS |
| A4 结果时效 | 运动到隐藏 P90 <= 150ms；末次运动到提交 P90 <= 2000ms；无重复/过期呈现 | 25ms；1370ms；隐藏、完成、呈现均 30/30 且每轮一次 | PASS |
| A7 原子呈现 | 每轮只呈现一个 `atomic_group=true` 结果组 | 30/30；呈现耗时 P90 14ms | PASS（子项） |
| A7 非文本保护 | 固定标记 SSIM >= 0.97；浏览器栏 SSIM >= 0.99 | 1.000000；1.000000 | PASS（子项） |
| A7 完整观感 | 无持续中英混排、无明显矩形底板、非文字内容不被污染 | 图表/标记保持，但灰色分块、代码混排和段落切碎仍可见 | PARTIAL |
| A8 触摸透传 | 控制条外 30 次点击和滚动均由底层网页响应 | 滚动 30/30；固定控件点击 30/30 | PASS |
| A9 原文切换 | 切换前后滚动锚点偏移 <= 16px | 最大偏移 0px | PASS |
| A5/A6 覆盖与语义 | 需要人工文字框、黄金原文与黄金译文 | 未提供；失败区域累计 17，拉丁字符残留率 P90 5.71% 仅作观察 | NOT EVALUATED |

补充性能：处理总耗时 P90 571ms，捕获到提交 P90 705ms，运动到隐藏最大 37ms，末次运动到提交最大 1512ms。

## 5. 范围：本周做什么、不做什么

本轮做：Xiaomi 单机、竖屏亮色、英文技术长文、普通 `alpha=0.72` 局部背景、30 次连续滚动、点击透传、空闲检查、原文切换和非文本像素保护。

本轮不做：暗色页面、横屏、中译英、第二品牌设备、退出后 Window/MediaProjection 资源审计、人工 CER/WER、黄金译文评分，以及主题色/高斯背景 A/B。这些仍需按 50 黄金视口矩阵独立验证。
