# Admin 服务端分页与回贴截图切换验证

## 改造内容

- `/admin/requests` 增加 `page`、`pageSize` 查询参数，默认 `page=1&pageSize=20`。
- Web 提供 20、50、100 条三档页容量，并保留状态和 v2/v3 过滤条件。
- 服务端先完成状态、协议版本过滤，再计算 `total/totalPages` 和当前页，避免先截断数据后过滤。
- 超出总页数的 `page` 自动回落到末页；非 20/50/100 的 `pageSize` 使用默认 20。
- 历史页采用固定视口结构：页眉、统计、筛选和底部分页不进入列表滚动区；表格独立上下/左右滚动，表头固定。
- 详情页使用一个宽度不超过 360px、高度不超过 460px 的共享画框，默认显示翻译前原图。
- “显示端侧实际回贴”复选框紧邻“翻译前 OCR 采集图”标题；勾选时只替换共享画框中的图片和元数据，不新增面板、不改变页面占位。
- 两张长截图均使用 `object-fit: contain` 等比完整显示；图片视图绝对定位在画框四边，避免固有图片高度撑开 Grid 后被外层裁切。没有回贴图时复选框禁用。

## 验证

- Rust 17 个单元测试、7 个 API 测试通过。
- 数据库测试写入 45 条混合 v2/v3、成功/失败记录，验证过滤后分页、末页回落和组合条件。
- 当前真实数据库 101 条记录：默认 20 条/页，共 6 页；第 2 页返回 20 条。
- 仅 v3 过滤得到 30 条：第 2 页返回 10 条，页容量与版本选项保持选中。
- 100 条模式下表格 `scrollHeight=4738px`、可视高度 `453px`；表格滚动 1800px 后页面 `scrollY=0`，页眉顶点仍为 0，分页底边仍在视口内。
- 355px 手机宽度下表格独立滚动，顶部筛选和底部分页同时可见，页面本身无横向溢出。
- 桌面实测共享画框切换前后均为 `360 x 456.45px`，`top=315.25px`，尺寸和位置完全一致。
- `367 x 847` 回贴长图修复后使用 `contain`，图片元素被限制在 `356 x 452.45px` 画框内容区内，整图可见且保持原始宽高比。
- 390px 手机宽度下共享画框为 `351 x 460px`，标题与复选框保持同排，页面无横向溢出。
- 浏览器控制台 0 错误。

## 结论

历史记录数量和单页容量不再影响页眉、筛选和分页操作；用户始终可以确认当前范围并切换页面。详情页继续以原图和服务端/Web 布局还原为主要信息，端侧回贴截图作为同画框内的按需对照材料。切换不再引发尺寸跳变，长截图也不会被裁切。
