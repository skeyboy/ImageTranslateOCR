# 羽化主题与高斯材料 50 视口验证

> 执行日期：2026-07-29
>
> 正式设备：Google Pixel 3，Android 15，1080x2160，USB ADB
>
> 输入：高准确 OCR 框与人工可接受译文的确定性上限
>
> 基线：普通悬浮窗 `alpha=0.72`、局部 `STANDARD` 背景

## 1. 结论

“主题色或高斯模糊后，译文字形不再设置自己的矩形背景”在技术上可行，但能否真正消除灰色贴片感取决于悬浮层透明度和信任级别。

| 场景 | 机器结果 | 人工 A7 材料观感 | 决策 |
| --- | --- | --- | --- |
| 普通 `alpha=0.72` 羽化主题色 | 50/50 | 硬边消失，但灰色条带仍明显 | 仅人工体验，默认关闭 |
| 普通 `alpha=0.72` 羽化高斯 | 50/50 | 灰条仍在，且有轻微原文模糊残影 | 不推荐，保留实验 |
| Enhanced `alpha=1` 羽化主题色 | 50/50 | Light/Dark 基本无独立底板，接近页面原生文字 | 下一阶段首选候选 |
| Enhanced `alpha=1` 羽化高斯 | 50/50 | 灰条消失，但原文轮廓仍形成模糊纹理 | 不推荐作为默认 |

普通模式的问题不是高斯半径或羽化宽度，而是 Android 非可信全屏悬浮层的安全透明度。`alpha=0.72` 时，为在任意底色上完全消除高对比原文，可稳定到达的目标通道约为 72-183；浅色页面会压成灰色，暗色页面会抬成中灰。若直接恢复页面白色/黑色，就会因为补偿值超出 0-255 而重新暴露原文字形。

Enhanced 使用可信 Accessibility Overlay，译文窗口可以 `alpha=1`，因此局部主题色能准确重建原页面表面。译文绘制在独立的羽化材料层上，不再绘制自己的矩形底板；非文字内容、系统栏和浏览器栏仍不进入材料范围。

本轮生产决策：普通模式默认仍为背景关闭和 `alpha=0.72`；现有“主题色/高斯模糊”人工开关改用羽化局部材料。Enhanced + 羽化主题色进入下一阶段候选，但在完成真实 Accessibility、连续滚动和触摸透传验证前不自动启用。

## 2. 目标：最终要证明或交付什么

证明以下问题：

1. 主题色和高斯是否可以从“文本矩形底板”改为独立的局部材料层。
2. 羽化能否消除材料硬边，同时保持文字核心对原文的遮盖强度。
3. 普通 `alpha=0.72` 与 Enhanced `alpha=1` 的体验差异是否来自透明度约束，而不是 OCR 或翻译精度。
4. 候选是否保持字号、对比度、非文字内容和系统/浏览器 Chrome。

交付物：两个默认关闭的羽化背景模式、50 视口五方 A/B、逐视口 JSONL、机器汇总、联系表、代表样本和真机自动化脚本。

## 3. 真实场景：用户实际如何使用

普通模式用户开启悬浮翻译后，底层网页必须继续接收点击和滚动。Android 会把非可信全屏悬浮层的组合不透明度限制在安全范围，所以普通译文窗口维持 `alpha=0.72`。

Enhanced 模式由用户显式启用 Accessibility 能力，使用可信 `TYPE_ACCESSIBILITY_OVERLAY`。控制条与译文层已经是两个独立窗口：控制条继续保持自身材料；译文层可使用 `alpha=1`，但只绘制局部文字材料，透明区域仍显示原网页。

本轮 50 视口沿用五类确定性场景，每类 10 个：Light 正文、Dark 正文、非文字/图表混排、横屏边缘、0.5-2.5 倍译文长度压力。每个视口输出 Source、Standard、普通羽化主题、普通羽化高斯、Enhanced 羽化主题和 Enhanced 羽化高斯。

## 4. 方案：主题色和高斯如何处理

### 4.1 材料与文字分离

每个 OCR 区域先生成独立材料位图：

1. 估计文字框周围的局部主题色，而不是使用全页单色。
2. 主题候选直接生成局部目标表面；高斯候选先对源区域降采样模糊，再混入局部主题色。
3. 根据窗口 alpha 对材料做反向合成补偿。
4. 文字框核心保持完全不透明；只在文字框到材料边界之间使用 smoothstep 羽化。
5. 最后透明绘制译文，关闭渲染器原有的额外矩形背景。

因此“没有文本自身背景”不等于“没有任何遮盖层”。必须仍有材料层消除底层原文；区别在于材料由页面上下文生成、边缘羽化，并可在相邻区域视觉上融合，而不是由每段译文直接画一块硬灰色矩形。

### 4.2 为什么不使用整页主题色或整页高斯

- 整页主题色会删除图表、图片、代码容器和页面层级。
- 整页高斯会模糊非文字内容、系统栏和浏览器栏，并增加全屏位图内存。
- 普通全屏 `alpha=1` 非可信悬浮层可能触发 Android 的触摸遮挡保护，不能以视觉效果换取 A8 失败。
- 局部羽化材料只改变 OCR 文字附近，保留页面空间结构和底层交互。

## 5. 验收：逐项列出可操作标准

| 项目 | 标准 | 正式实测 | 判定 |
| --- | --- | --- | --- |
| 视口完整性 | 5 类 x 10 = 50 | 50 | PASS |
| 结构渲染 | 每个候选 50/50；覆盖 min=100%；裁剪=0 | 五个配置均 50/50、100%、0 | PASS |
| 字号 | 最小字号比例 >= 0.50 | 全部候选最低 0.778 | PASS |
| 对比度 | 最低 >= 4.5:1 | 普通候选 5.54:1；Enhanced 5.79:1 | PASS |
| 材料硬边 | 边界变化 max <= 15% | Standard 100%；四个羽化候选 0% | 候选 PASS |
| 原文细节抑制 | 主题 max <= 20%；高斯 max <= 35% | Enhanced 主题 max 0.069%；Enhanced 高斯 3.58% | PASS |
| 非文字保护 | 保持率 >= 99%，无保护区相交 | 所有候选 100%，相交 0 | PASS |
| Chrome 保护 | 保持率 >= 99.9% | 所有候选 100% | PASS |
| 材料变更面积 | Enhanced 应显著低于普通候选 | 主题 P90 3.29% vs 24.41%；高斯 5.89% vs 24.40% | PASS |
| 性能 | 高斯 P90 <= 200ms | 普通 120ms；Enhanced 116ms | PASS |
| 普通 A7 材料观感 | 无明显灰条、无原文模糊残影 | 仍有灰条；高斯有残影 | PARTIAL |
| Enhanced 主题 A7 子项 | 无明显独立底板、无残影、页面层级保留 | Light/Dark/图表样本通过 | PASS（确定性子项） |
| Enhanced 完整验收 | 真实 Accessibility、30 次滚动/点击、第二设备 | 尚未执行 | NOT EVALUATED |

完整汇总中，Enhanced 羽化主题色的原文细节保留 P50/P90 为 0/0，材料变更面积 P50/P90 为 2.09%/3.29%，渲染 P50/P90 为 111/124ms。Enhanced 高斯虽通过机器门，但细节保留 P90 为 3.50%，截图可见模糊残影，因此人工决策低于主题色。

## 6. 范围：本周做什么、不做什么

本轮做：材料与文字分离、主题/高斯局部材料、羽化边缘、普通与 Enhanced alpha 对照、50 个确定性视口、Light/Dark、图表、横屏、长度压力、Pixel 3 真机自动化和人工截图复核。

本轮不做：重新评估 OCR/翻译准确率、修改生产默认、自动打开 Accessibility、真实网页连续滚动、30 次触摸透传、退出资源审计、功耗和 Xiaomi 正式复验。确定性输入只验证渲染材料，不替代 A5/A6。

## 11. 后续开发引用

涉及背景体验开关、Window alpha、Accessibility Overlay、主题估计、模糊参数、材料边界或译文绘制的修改，必须重跑本矩阵。Enhanced 候选只有在本矩阵、连续滚动 A3/A4、触摸透传 A8、原文切换 A9 和退出生命周期 A11 同时通过后，才能讨论扩大开放范围。

人工复核依据克制材料、明暗主题一致性、空间连续和非文字层级原则：主题材料应退到内容之后，不能以模糊纹理或灰色条带成为页面最强视觉层级。
